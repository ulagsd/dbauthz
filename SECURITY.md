# Security Policy

dbauthz holds references to privileged database credentials and changes database
permissions. Security reports get priority.

## Reporting a vulnerability

Report privately through GitHub's
[private vulnerability reporting](https://github.com/ulagsd/dbauthz/security/advisories/new).
Do not open a public issue.

Include the affected version or commit, the steps to reproduce, and the impact
you observed. You will get an acknowledgement within five working days.

## Supported versions

dbauthz is pre-release. Only the latest commit on `main` receives fixes until
v1.0.0.
